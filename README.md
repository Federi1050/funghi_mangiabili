# funghi_mangiabili

## Componenti del progetto
Brivio Emanuele - Combi Federico

## Consegna
il progetto consisteva nel creare una regressione logistica e una random forest per la predizione, tramite machine learning.

La variabile target è "poisonus" ovvero se il nostro fungo e' velenoso o meno

Il dataset e' presente al seguente link [Mushroom](https://archive.ics.uci.edu/dataset/73/mushroom)

L'immagine del container e' al seguente link [immagine](https://hub.docker.com/r/f3d3ri/funghi_velenosi)
